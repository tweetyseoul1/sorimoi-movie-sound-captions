# 실제 AI 효과음 인식 시험 결과

참고 자막 11개 구간 중 같은 소리 종류가 겹친 구간은 0개입니다.

- 같은 종류 감지: 0개
- 비슷한 종류만 감지: 0개
- 다른 종류로 분류: 0개
- 해당 효과음 후보 없음: 10개
- 모델에 하품 분류 없음: 1개
- 같은 종류이며 양 끝 시각이 참고 자막의 ±1초 안: 0개

## 시험 방법

공개 영화 Big Buck Bunny의 원본 00:30~01:30 구간을 기존 AST 모델로 실제 분석했습니다. 참고 자막은 모델 입력에 넣지 않았습니다. 실행 후 Demuxed의 공개 접근성 자막 11개 구간과 비교했습니다. 같은 파일인지 SHA-256으로 검증했습니다.

이는 공개 자막과의 구간별 비교이며 정확도 점수가 아닙니다. 소리 원인과 세밀한 시작·끝까지 맞았다는 뜻도 아닙니다. 같은 AI 후보가 여러 참고 구간과 겹칠 수 있습니다.

## 팀에 설명할 내용

“같은 영화 1분을 AI에 넣어 효과음과 발생 시간을 추출하고, 공개 접근성 자막과 비교했습니다. 참고 자막 11개 구간 중 같은 소리 종류가 겹친 구간은 0개입니다. 배경음악과 겹친 효과음, 이 모델에 분류 항목이 없는 하품 등이 한계입니다. 기존 자막에 적힌 소리를 AI가 인식한 것처럼 제시하지 않았습니다. 정답률 80%를 달성했다고 말할 근거는 아직 없습니다.”
